# Prompt 工作台

模板数据存本地 JSON 库，由 scripts/store.py（纯 Python 标准库）读写。所有确定性的增删查改必须走脚本，不要手写 JSON。

## 存储位置
- 默认 `~/.prompt-workbench/store.json`；可用环境变量 `PROMPT_STORE` 或脚本 `--store` 参数覆盖。
- 库不存在时脚本自动创建。

## 脚本命令
运行 `python <本技能目录>/scripts/store.py <子命令>`：
- `add --name 名称 (--body "文本" | --file 路径) [--tags a,b]`
- `list` ／ `show --name 名称` ／ `delete --name 名称`
- `edit --name 名称 (--body | --file)` → 自动追加新版本，旧版本全部保留
- `versions --name 名称` ／ `diff --name 名称 --a 1 --b 2`
- `render --name 名称 [--version N] --var 键=值`（可重复）→ 缺变量时报错并列出缺失项

## 工作流
1. **保存模板**：把用户给的提示词整理成模板，可变部分参数化为 `{{变量}}`（变量名用字母/数字/下划线），向用户确认变量清单后 add。
2. **使用模板**：render 填充变量后，由你执行渲染出的提示词完成用户任务；缺变量先问用户，不要猜值。
3. **版本对比（A/B）**：
   - 先 diff 看文本差异；再 render 用同一组变量分别取两个版本的实际输入；
   - 分别执行两个版本（同一任务、同一输入），并排展示输出；
   - 给出点评：正确性、指令遵循、输出格式、稳定性，附推荐与理由。点评必须基于两版真实输出，不得凭空推断。
4. **删除**须用户点名模板；**编辑**前先 show 当前版本内容给用户看。

## 硬约束
- 模板中不得存入密钥等敏感信息，发现时提醒用户剔除。
- 脚本报错先读错误信息修正调用，不得绕过脚本直接改 JSON 库。
